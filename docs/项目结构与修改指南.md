# 项目结构与修改指南

## 页面如何工作

打开首页时，`app/page.tsx` 渲染 `PortraitHall`。`app/layout.tsx` 设置页面语言、标题、描述和全局样式。页面从 `data/members.ts` 读取成员资料，每人有独立图像、编号、查找名称和稳定的 `memberId`。`data/portrait-layout.ts` 把两套分排配置换算成坐标，组件把坐标传给 CSS，浏览器把每张图定位到舞台。

搜索先规范化输入，可以识别全角数字和开头的井号。匹配结果按编号或查找名称筛选。点击结果、按 Enter 或点击画面中的人物，都通过同一个 `memberId` 选中。该 ID 决定高亮、变暗和资料内容。窄屏打开底部资料面板时会滚动页面，把选中人物的脸带到面板上方。

直达链接读取 `?member=` 中的编号或查找名称。打开后，地址栏统一使用编号。旧的数字片段（如 `#014`）会在打开时转换。关闭资料时，链接只清理成员定位信息。

## 改动入口与画面变化

| 想改什么 | 在哪里改 | 可观察到的变化 |
| --- | --- | --- |
| 改成员的查找名称 | `data/members.ts` 的 `roster` | 搜索命中词、结果名称、资料标题和人物的可访问名称随之更新 |
| 改某人的简介或资料 | `data/members.ts` 中成员的 `profile` | 点开该人物后显示新的资料。没有完整资料的成员使用简版面板 |
| 调换两人的位置 | `data/portrait-layout.ts` 的 `slots` | 两人交换在合影里的位置，编号和搜索结果仍对应原人物。桌面与手机分别调整 |
| 一排更宽、更低或更大 | 同文件的 `left`、`right`、`y`、`baseScale` 和 `stepScale` | 调大横向范围会拉开一排，调大 `y` 会下移一排，调大缩放会增加前后遮挡 |
| 改搜索行为或高亮后滚动 | `components/portrait-hall.tsx` 的匹配与 `selectMember` | 结果筛选、选中状态或目标在屏幕上的位置变化。修改后验证空结果、编号、名称和连续切换 |
| 改颜色、合影比例、亮暗或点击区 | `app/globals.css` | 主题色、舞台高宽、前后排观感或卡片可点区域变化 |
| 改背景或站台装饰 | `public/assets/backgrounds/sunlit-paper.svg` 与 `.stage` | 舞台色彩、弧线和星点变化，人物图片仍按各自图层显示 |

### 排布规则

行从后到前定义。每个 `slots` 值对应成员编号的数字部分，桌面和手机各应恰好使用每个编号一次。行内从 `left` 到 `right` 均布，`y` 按舞台高度的百分比计，以卡片中心为锚点。前排图层高于后排，选中时用白边和光晕标记。屏幕宽度不超过 600 像素时用手机五排。宽度不超过 900 像素时用底部资料面板。

**示例。** 想拉开桌面第二排，可以把第二排的 `left` 从 13 调到 11，`right` 从 87 调到 89。改完查看 1440 × 900 的全景与打开右侧资料后的画面，再点两端人物和邻近人物。

### 替换占位形象

新画像获准公开后，用约 3:4 的 WebP 展示图替换占位 SVG，再更新 `data/members.ts` 中对应的 `avatar`。将保留完整头部的方形 WebP 头像存入 `public/assets/profiles/`，沿用合影画像的文件名。同时检查合影裁切、名片头像和点击位置。

### 人物档案与光锥

`MemberDossier` 根据成员的 `lightCone` 配置显示光锥。018 的「长夜月」样卡由 RuiC Card Skill 生成，网页素材在 `public/light-cones/member-018/`。宽屏上光锥和档案等高并排，宽度不超过 740 像素时先显示档案，再显示光锥。可用 `/?member=018` 检查拖动、翻面和关闭档案。

### 如何复现并解释改动

从 [README](../README.md) 启动，与当前桌面和手机截图对照。先看全景，再试编号 `001`、`028`，以及链接 `/?member=014`。连续点击前后排后，检查高亮和资料是否同时切换。关闭资料或清空搜索后，确认能回到全景。若改动视觉，记录生效的文件、改变的值和前后截图。
