# 第六组 · 28 人排布自测

在 Windows 本地运行生产构建，用 Playwright Chromium 验证桌面鼠标和两种触控视口。每个视口逐一点选 28 位成员，再验证搜索、连续切换和直达链接。

| 浏览器与视口 | 结果 |
| --- | --- |
| Chromium 1440 × 900，桌面鼠标 | 通过 |
| Chromium 390 × 844，触控模拟 | 通过 |
| Chromium 600 × 800，触控模拟 | 通过 |

## 检查结果

- 28 张 WebP 合影画像和 28 张名片头像均可独立加载，合影卡片无文字标签。逐个点选后，资料面板的编号和头像与选中成员对应。
- 全角编号和查找名称可用于查找。点击结果或按 Enter 能定位目标，无结果时显示提示。
- 资料面板打开时，可连续点击邻近卡片并更新资料。关闭资料或清空搜索可取消选中。
- 旧链接 `#014` 打开后会转成 `?member=014`，关闭并刷新时恢复合影。查找名称也可用于直达链接。
- 桌面显示右侧名片。窄屏滚动到目标人物，使其脸部位于底部面板上方。
- 打开 018 时，宽屏显示等高的光锥与档案，窄屏纵向排列。光锥可翻面，聚焦光锥时按 Esc 可关闭档案。
- 各测试视口未出现页面横向溢出或页面脚本异常。
- TypeScript 检查和生产构建均通过。

## 验收边界

手机结果来自触控模拟，iOS Safari 和安卓真机体验仍待验收。短屏上的完整资料可以在面板内滚动。
